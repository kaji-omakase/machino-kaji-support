# まちの家事サポート（仮）ホームページ

勝どき・月島エリア向けの、スマートフォン対応・1ページ型家事代行サイトです。

## ファイル
- `index.html`：ページ本文
- `style.css`：デザイン・スマートフォン対応
- `script.js`：メニューなどの動作

## GitHub Pagesで公開する方法
1. GitHubで新しい公開用リポジトリを作成（例：`machino-kaji-support`）。
2. このフォルダ内の3ファイルを、リポジトリの一番上（root）にアップロード。
3. `Settings` → `Pages` → `Deploy from a branch` を選択。
4. Branchを `main`、フォルダを `/(root)` にして保存。
5. 表示されたURLで公開を確認。

## 公開前に必ず変更する箇所
- 仮サービス名「まちの家事サポート」
- `index.html` 内の `CONTACT-EMAIL-TO-BE-SET@example.com` を実際に受信できるメールアドレスへ変更
- 正式な電話番号、料金、営業時間、対応範囲、事業者情報
- 画像はUnsplashの外部画像を参照しています。継続利用する画像の利用条件と表示可否を確認してください。
- 実際の提供内容・スタッフ体制・資格等に合わせて、介護・身体介助に関する説明を確認してください。

## 注意
現在の料金は確定額を表示せず「設定中」としています。問い合わせ先も仮のメールリンクです。このまま営業用サイトとして公開せず、実際の連絡先・事業者情報を設定してから公開してください。
